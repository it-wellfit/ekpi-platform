# Triage label mapping

The skills use five canonical triage roles. Their current GitHub label mapping is:

| Matt Pocock role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer must assess the issue |
| needs-info | needs-info | Waiting for missing information |
| ready-for-agent | ready-for-agent | Specified and ready for implementation |
| ready-for-human | ready-for-human | Requires human work or decision |
| wontfix | wontfix | Will not be actioned |

This mapping does not create labels. No origin or authenticated GitHub session is available in this checkout, so provision these labels and the wayfinder:* labels after the existing repository is connected. When a skill names a canonical role, use the mapped string above.
